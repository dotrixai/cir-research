# Security

This repository contains documentation only. It should never contain credentials, keys, private data, internal infrastructure details, model weights or source code.

If you find anything in this repository that looks like a secret, personal data or an accidental disclosure, or a vulnerability in any DotrixAI property:

- **Do not** open a public issue or post it anywhere public.
- Email **novenrizkia.8.5.6@gmail.com** (the contact address published at https://dotrixai.com/contact) with a description, the file and commit, and how you found it.

We will acknowledge the report and remove or rotate anything exposed. Please give us reasonable time to act before any disclosure.
